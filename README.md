# virtual-park

> 遊びが置いてある場所じゃなくて、**遊びが生まれる場所**。

昔の公園では、誰かが「ここからあそこまで、鬼に捕まらずに行けたら勝ちな！」と言い出して、みんなが乗ったらそれで遊びが始まっていた。
それをオンラインでやれる場所をつくる。

---

## これは何じゃないか

| | 中心にあるもの | このプロジェクトとの違い |
|---|---|---|
| Minecraft 系 | 世界を作る | 作りたいのは世界じゃなくて「遊び（ルール）」 |
| Roblox 系 | 作者が作ったゲームを、他の人が遊ぶ | 作る人と遊ぶ人が分かれていない。遊んでる最中にルールが変わる |
| ミニゲーム集 | 運営が用意した遊びを選ぶ | 用意された遊びは出発点にすぎない |

## コアの体験

1. 公園に人がいる
2. 誰かが遊びを提案する（定番でも、思いつきでも）
3. その場の人がルールを足したり変えたりする
4. 納得したら、すぐ始まる
5. 面白かったら保存して、次の人が引き継げる・改造できる

プログラミング不要。公開審査不要。ダウンロード不要。

## 遊びの3つの出どころ

- **定番の遊び** — 缶蹴り・鬼ごっこ・かくれんぼなど2〜3個。人が来たらすぐ遊べる
- **運営のイベントセット** — 期間限定の道具やルール。「公園に新しい遊具を持ってくる」感覚
- **ユーザー発の遊び** — 「缶を3個にしたら？」「陣取りと鬼ごっこ合体させよう」

人気のユーザー発の遊びは、公式セットやイベントに採用されることもある。

## 遊びの部品（たたき台）

何でも作れる必要はない。少ない部品の組み合わせで、たくさんの遊びが作れればいい。

- **動き**: 移動する / 物を置く・拾う・投げる
- **判定**: 触れたら / 範囲に入ったら・出たら / 時間切れになったら
- **役割**: 鬼・逃げる人・チーム / 交代の条件
- **結果**: 得点 / 捕まる・脱落・復活 / 勝利条件
- **合意**: 提案 / 投票 / 開始
- **道具**: 線、ベンチ、ボール、旗、缶、マス目 …

## ロードマップ（仮）

- **Phase 0** — 公園マップ1つ＋缶蹴り1つ。数人が同時に入って遊べる
- **Phase 1** — 定番を2〜3個に。既存の遊びのパラメータ（人数・時間・鬼の数など）をその場で変更できる
- **Phase 2** — 部品の組み合わせで新しい遊びを作れる。保存・共有・派生
- **Phase 3** — 運営イベントセット。人が集まってきたら看板広告・着せ替え・公園の装飾など

収益化は「人が集まってまた来たくなる」が成立してから。

  ← ここがたぶん一番の核心

- 荒らし・変なルールへの対処
